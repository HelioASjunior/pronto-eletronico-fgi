# Ponto Eletrônico - Tela de Login

Tela de login de um sistema de ponto eletrônico, feita com **HTML**, **CSS** e **JavaScript**.

## Estrutura do projeto

```
PontoEletronico/
├── index.html     -> tela de login (estrutura da página)
├── css/
│   └── style.css  -> visual da página (cores, tamanhos, posições)
├── js/
│   └── script.js  -> botão do olho para mostrar/ocultar a senha
└── paginas/       -> outras páginas do sistema
```

## O que cada parte faz

- **HTML**: diz *o que* aparece na tela (título, campos, botões).
- **CSS**: diz *como* aparece (cores, fontes, espaçamentos).
- **JavaScript**: diz *o que acontece* quando o usuário interage (clicar no olho mostra a senha).

## Como abrir

1. Baixe ou clone este repositório.
2. Dê dois cliques no arquivo `index.html` para abrir no navegador.

Se estiver usando o XAMPP, coloque a pasta dentro de `htdocs` e acesse:
`http://localhost/PontoEletronico/`

## Dica para estudar

Todos os arquivos têm **comentários** explicando cada parte do código.
Abra o `index.html`, o `style.css` e o `script.js` e leia os comentários com calma.
Tente mudar uma cor no início do `style.css` (nas variáveis) e veja o que acontece!
